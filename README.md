# Voosada

Site institucional em português para a Voosada — boutique hotel e destination flight club no sul da Bahia.

## Publicação

O site é estático e pode ser publicado diretamente pelo GitHub Pages a partir da branch `main`.

## Conteúdo

- conceito e filosofia do lugar;
- localização e experiência do hóspede;
- programa arquitetônico: 8 apartamentos compactos, 4 amplos e cobertura aberta;
- primeira etapa com 8 módulos de glamping;
- modelo preliminar de receita, CAPEX e implantação.

As visualizações arquitetônicas são conceituais. Os números apresentados são hipóteses de trabalho e não constituem projeção financeira.
